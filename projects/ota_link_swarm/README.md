# ota_link_swarm

Excel-driven OTA link selector-swarm workflow.

- Config: `config.yaml`
- Project workflow descriptor: `workflows/main.yaml`

Run:

```bash
python main.py --audit-workflow projects/ota_link_swarm/workflows/main.yaml
python main.py --run-yaml projects/ota_link_swarm/workflows/main.yaml
```
