# Windows desktop discovery

Recon-only. Execution uses desktop ops (`desktop_launch`, `desktop_inspect`,
`desktop_read`, `desktop_focus`, `desktop_type`, `desktop_select`,
`desktop_click`, `desktop_capture`) through the application seam.

Coordinate fallbacks are weak, approval-gated, and require verification.

Canonical authoring: `rpa-harness-automation-builder`.
